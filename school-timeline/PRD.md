# 스쿨타임라인: 검색 유입형 교육 계산기 MVP 기획서

작성 기준일: 2026-11-04 (대한민국)
상태: 개발용 기획 초안. 출시 전 공식 출처·연도별 변경 사항 재검토 필수.

## 0. 사업 가설과 전략
- 목표: 검색 유입을 기반으로 유용한 무료 계산기를 제공하고, 장기적으로 Google AdSense 광고 수익화.
- 첫 타깃: 2027학년도 초등 입학을 준비하는 보호자 및 자녀의 현재 학년/향후 학사 일정을 확인하려는 가족.
- 핵심 차별점: 입학년도 숫자 하나가 아니라 **취학 일정과 초·중·고 12년 타임라인, 개인화된 준비 체크리스트, 인쇄·일정 다운로드**까지 한 곳에서 제공.
- 이미 학년·입학년도 계산기가 존재하므로 복제 서비스 금지. 경쟁 서비스 참고: https://tools.mayalibrarywiki.com/school-year-calculator
- 초기 범위는 교육·입학 주제로 한정. 미래 키(의학적 추정)와 MBTI(오락용)는 별도 검증 후 각기 독립 사이트/브랜드로 확장.
- 검색량/수익은 현재 미검증. 예상 페이지뷰·RPM을 사실처럼 쓰지 말 것.

## 1. 서비스 원칙
1. 로그인 없음, 무료, 모바일 우선, 10초 내 주요 결과.
2. 결과 계산에 필요한 생년월일은 브라우저 안에서만 처리하며 서버·분석 도구·공유 URL로 전송하지 않음.
3. 주민등록번호, 자녀 이름, 연락처 수집 금지.
4. 교육행정 안내는 '법령상 일반 기준'과 '지역·학교별 확인 필요 항목'을 구별.
5. 결과 페이지는 얇은 SEO 자동 생성 페이지가 아닌 사람에게 유용한 설명을 포함.
6. 학교 배정, 예비소집일, 온라인 발급 시작일 등 검증되지 않은 개별 사실은 단정하지 않음.

## 2. MVP 기능 (P0)
### F01. 생년월일 기반 학년·입학년도 계산
입력:
- 생년월일(YYYY-MM-DD, 필수; 달력 또는 텍스트 입력)
- 입학 방식: 정상 / 1년 조기입학 / 1년 입학연기(선택; 기본 정상)
- 실제 초등 입학년도 직접 입력(선택; 있는 경우 다른 입학 방식보다 우선)
- 기준일(선택; 기본 브라우저 현재일, Asia/Seoul; YYYY-MM-DD)
출력:
- 법정 기준 초등학교 입학년도
- 선택·실제 입학년도 반영 결과
- 기준일의 학년도와 초등·중등·고등 학년(또는 입학 전/고교 졸업 후)
- 초1~초6, 중1~중3, 고1~고3의 해당 연도 목록, 표 및 세로 타임라인
- 초등학교 입학 예상 연도, 중학교 진학 예상 연도, 고등학교 진학 예상 연도, 고등학교 졸업 예상 연도
- 일반 학제 가정 안내: 휴학, 유예, 조기졸업, 해외학력, 검정고시, 학교별 일정은 별도

계산 규칙:
- 정상 초등 입학년도 = 출생연도 + 7 (달/일 무관)
- 1년 조기 = 정상 - 1, 1년 연기 = 정상 + 1
- 실제 입학년도 입력 시 해당 값을 최종 입학년도로 사용
- 기준일 기준 학년도 = 기준일이 3월 이후면 기준연도, 1~2월이면 기준연도 - 1
- 초등 1학년의 연도 = 최종 입학년도. 초6 = +5. 중1 = +6. 중3 = +8. 고1 = +9. 고3 = +11. 일반적 졸업·다음 진학 = +12.
- 계산 데이터 모델은 날짜를 날짜 전용 형식으로 검증. 시간대/UTC 파싱으로 생일이 하루 밀리지 않도록 주의.
- 생년월일 범위: 1900-01-01부터 오늘까지로 제한(미래 출생일 불허). 너무 오래된 출생연도는 교육 계산 지원 범위를 좁히고 친절하게 안내해도 됨.

### F02. 2027학년도 초등 취학 준비 허브
- 고정 공개 페이지: `/admission/2027/`
- 누구 대상인가? 기본적으로 2020년 1월 1일~12월 31일 출생자. 조기입학/입학연기 등 예외 명시.
- 법령에 따른 일정 안내(출처 바로 아래 표시):
  * 2026-10-01 취학아동명부 조사 기준일
  * 2026-10-31 취학아동명부 작성 기한
  * 2026-11-30 입학기일·통학구역 통보 기한(교육장→읍면동)
  * 2026-12-20 취학통지 기한
  * 2026-10-01~12-31 조기입학 또는 입학연기 신청 기간(해당 보호자)
- 날짜 표현 시 법정 기한과 실제 관공서 서비스 오픈·학교별 일정을 명확히 분리.
- 예비소집·학교 배정·정부24 온라인 발급일: **검증한 2027학년도 공식 공지가 없으면 날짜를 넣지 말고 '관할 교육청/학교 확인' 안내 및 공식 링크 제공**.
- 학교별 행사일·배정학교를 자동 추정하지 않음.
- 정부24 공식 링크, 법령 링크, 교육청 확인 방법 안내.

### F03. 개인화 체크리스트
- 항목: 취학통지 확인, 배정학교 확인, 학교별 예비소집 공지 확인, 준비물·돌봄 안내 확인 등.
- 체크는 메모리에서만 유지. 첫 출시에는 서버 저장 없음. 로컬 저장은 별도 사용자 동의 기능으로 2차에 고려.
- '인쇄하기' 버튼은 브라우저 인쇄 스타일로 구현.
- '일정 파일(.ics) 만들기'는 **공식적으로 검증된 일반 기한만** 포함. 개별 입학식·예비소집일은 포함하지 않음.
- 모바일 공유는 개인정보가 없는 페이지 URL을 공유. DOB/개인별 결과를 URL에 붙이지 않음.

### F04. 신뢰·콘텐츠·운영 페이지
- `/` 홈페이지: 2027년 입학 허브 + 계산기 진입 + 대표 설명
- `/school-year/` 계산기와 계산법/예시/예외 설명
- `/admission/2027/` 연도별 취학 안내·체크리스트
- `/methodology/` 출처·수정 이력·업데이트 기준
- `/about/`, `/privacy/`, `/contact/` 운영 정보
- `404`, `sitemap.xml`, `robots.txt`, favicon, OG 이미지

- 지역별 교육청 공식 링크 디렉터리(수동 검증된 자료만).

## 5. SEO 전략
- 주력 키워드(검색량 검증 전 가설): 2027 초등학교 입학, 2020년생 초등학교 입학, 초등학교 입학년도 계산기, 몇 년생 몇 학년, 초등 취학통지서 2027.
- 첫 화면 서버/정적 HTML에 제목·도움말·출처·본문이 있어야 함. 계산기 로직만 브라우저 JS 사용.
- 각 URL은 고유 검색 의도·고유 콘텐츠를 가져야 함. 생년월일 숫자별 수천 개 유사 URL 생성 금지.
- 페이지별 title/h1/meta description/canonical/Open Graph 제공; sitemap 제출; 내부 링크 연결.
- JSON-LD는 실제 콘텐츠에 부합하는 `WebSite`, `WebPage`, `BreadcrumbList` 정도만 적용하고, 풍부한 검색결과 보장 금지. FAQ rich result 같은 폐지 기능에 의존 금지.
- 최초 GSC 등록, 사이트맵 제출, 색인 상태 점검.
- 검색결과의 기존 학년 계산기와의 차별화 요소: 연도별 일람 + 공식 일정 체크리스트 + 프린트/ICS.

## 6. 애드센스 운영 원칙
- 애드센스 승인은 보장하지 않음. 충분한 독자적인 설명과 작동하는 서비스 확보 후 심사.
- 광고는 계산기 핵심 폼·결과 위에 과하게 끼워 넣지 않음. 광고와 버튼을 분명히 분리.
- 미완성 페이지, 빈 결과 화면, 광고만 있는 페이지에는 광고 금지.
- 개인정보처리방침과 사용 데이터 범위 설명. 사용자 입력 DOB를 추적 이벤트로 수집하지 않음.
- 매출 식: 월 페이지뷰 × 실제 페이지 RPM / 1,000. 예상 RPM은 실측 전 미지수.

## 7. 기술 선택
- Astro + TypeScript (정적 페이지, 필요한 계산기 컴포넌트만 클라이언트 JS)
- Tailwind CSS (프로젝트 초기 설치에서 안정적인 공식 절차 확인 후 적용)
- Vitest(순수 계산 함수 단위 테스트), Playwright(E2E 반응형)
- Cloudflare Pages, GitHub 저장소, `npm run build` → `dist`
- 데이터베이스, 인증, 유료 API, 서버리스 함수는 MVP에 없음.
- 사이트 도메인/이름 확정 전에는 `SITE_URL` 환경변수 또는 명시적 배포 설정 사용. 예시 도메인을 하드코딩해 배포하지 않음.
- 계산 로직은 프레임워크 의존 없는 `src/lib/schoolYear.ts`에 구현.
- 정책 데이터: `src/data/admission2027.ts`에 날짜, 제목, dateType(법정기한/참고), sourceUrl, verifiedAt, note 포함. 연도 변경 때 이 파일을 먼저 갱신.

## 9. 테스트 인수 조건
### 계산 사례
- 2020-12-31, 정상: 초1 2027, 중1 2033, 고1 2036, 고3 2038.
- 2020-01-01, 정상: 초1 2027(12월생과 동일).
- 2020-12-31, 조기입학: 초1 2026.
- 2020-12-31, 입학연기: 초1 2028.
- 2019-01-01, 정상, 기준일 2027-02-28: 2026학년도 초1.
- 2019-01-01, 정상, 기준일 2027-03-01: 2027학년도 초2.
- 2020-12-31, 정상, 기준일 2026-11-04: 초등 입학 전.
- 2020-12-31, 정상, 실제입학년도 2028 입력: 결과는 2028(override).
- 2020-02-30: 입력 오류, 계산 금지.
- 출생일이 미래인 경우: 입력 오류, 계산 금지.
- 기준일과 출생일의 시차/UTC로 학년이 뒤틀리지 않아야 함.
### 기술·UX
- 모바일 360px, 태블릿, 데스크톱 레이아웃 양호.
- 키보드만으로 입력/계산/인쇄 접근 가능. label·aria-live로 결과 전달.
- `npm run build`, `npm run test`, E2E 통과.
- 빌드 결과 `dist/`에서 최소한 주요 콘텐츠가 HTML로 확인됨.
- 모든 내부 링크, canonical, meta, robots, sitemap 검사.
- DOB가 GA4/GSC/URL/network로 유출되지 않음.
- 정보 검증이 되지 않으면 화면에 '확인 필요' 상태와 공식 출처 링크 표시.

- 4주: 페이지 색인 상태와 정책·UX 오류 점검(SEO 성과 성급히 판단 금지).
- 8~12주: 월별 자연검색 클릭 증가 추세 확인. 유입이 생기는 검색 의도 중심으로 콘텐츠 보완.
- 목표 예시(사업자가 수정 가능): 3개월 안에 주요 페이지 3개 이상 색인, 첫 자연검색 클릭 확보. 색인·수익 보장 없음.
- 신규 사이트 여러 개 동시 출시하지 말고 첫 사이트의 사용자 반응 및 색인 상황 관찰 후 확장.
